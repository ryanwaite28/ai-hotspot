# HotSpot Frontend Accessibility and E2E Foundation

## Required checks

- skip link reaches main content
- keyboard-visible focus for links, inputs, textarea, and buttons
- form labels are associated with controls
- route headings use one primary h1
- navigation has an accessible label
- sponsored campaign placements have visible sponsor labeling
- paid actions expose required entitlement reason without trusting browser state
- reduced-motion media behavior is honored

## Planned E2E flows

- register → verify email
- login → chronological feed
- compose text post
- upload media and watch processing state
- create/view story
- checkout subscription
- view moderation/settings
- enter live stream room
- account export/delete confirmation
